# E-Commerce Sales & Customer Analytics System

A data analytics project that analyzes e-commerce sales and customer transaction data to identify revenue trends, product performance, customer behavior, and regional business patterns.

The project combines SQL-based analysis, data cleaning, customer segmentation, and Power BI visualization to generate actionable business insights.

## Objectives

- Analyze e-commerce sales performance.
- Identify revenue and profit trends.
- Evaluate product performance.
- Analyze customer purchasing behavior.
- Segment customers based on their transaction history.
- Identify high-value and at-risk customers.
- Analyze regional sales performance.
- Build an interactive Power BI dashboard.

## Tech Stack

- SQL
- Python
- Pandas
- Data Cleaning
- Exploratory Data Analysis
- Power BI
- DAX
- CSV / Relational Database
